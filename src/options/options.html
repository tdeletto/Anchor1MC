Getting started

Three things to set up, then you can dictate anywhere in Chrome.

1. Microphone access

Chrome only lets an extension record after you grant the microphone once, from a page like this one.

Not checked

2. Pick a model

Parakeet V3 runs entirely on your Chromebook and is the most accurate on-device option. It is a large first download; Whisper base is a lighter start.

3. Learn the hotkey

Hold Right Alt and talk; let go and the text appears. Double-tap it to keep recording hands-free. On pages where extensions cannot run — chrome://, the Web Store, the PDF viewer — use Alt+Shift+D instead.
